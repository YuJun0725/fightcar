# d_image_deal

OpenCV 图像基本操作示例。

| 文件或目录 | 功能 |
|---|---|
| [get_size.py](<get_size.py>) | 读取图像尺寸等基本信息。 |
| [get_roi.py](<get_roi.py>) | 截取图像中的感兴趣区域（ROI）。 |
| [single_pixel.py](<single_pixel.py>) | 访问和修改单个像素。 |
| [split_merge.py](<split_merge.py>) | 分离和合并颜色通道。 |
| [image_add.py](<image_add.py>) | 图像加法和加权叠加。 |
| [flood_fill.py](<flood_fill.py>) | 从种子点进行泛洪填充。 |
| [cat.jpeg](<cat.jpeg>) | 图像处理示例素材。 |
| [dog.jpeg](<dog.jpeg>) | 图像处理示例素材。 |
