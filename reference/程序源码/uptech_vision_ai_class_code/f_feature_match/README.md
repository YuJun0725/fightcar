# f_feature_match

图像边缘、角点检测和匹配示例。

| 文件或目录 | 功能 |
|---|---|
| [canny.py](<canny.py>) | Canny 边缘检测。 |
| [harris.py](<harris.py>) | Harris 角点检测。 |
| [laplacian_sobel.py](<laplacian_sobel.py>) | Sobel 与 Laplacian 边缘检测。 |
| [shi_tomasi.py](<shi_tomasi.py>) | Shi-Tomasi 角点检测。 |
| [match_template.py](<match_template.py>) | 在图像中进行模板匹配。 |
| [orb_match.py](<orb_match.py>) | ORB 特征提取与匹配。 |
| [cat.jpeg](<cat.jpeg>) | 特征检测示例素材。 |
| [template.jpeg](<template.jpeg>) | 模板匹配素材。 |
| [orb-match-1.jpg](<orb-match-1.jpg>) | ORB 匹配示例素材。 |
