# l_face_reidentification/models

人脸检测与身份比对示例的模型资源。

| 文件或目录 | 功能 |
|---|---|
| [Pytorch_RetinaFace_mobile0.25-640-640.onnx](<Pytorch_RetinaFace_mobile0.25-640-640.onnx>) | RetinaFace 人脸检测 ONNX 模型。 |
| [ms1mv3_arcface_r18.onnx](<ms1mv3_arcface_r18.onnx>) | ArcFace 人脸特征提取 ONNX 模型。 |
| [ms1mv3_arcface_r18_rk3588_quantized.rknn](<ms1mv3_arcface_r18_rk3588_quantized.rknn>) | ArcFace 的 RK3588 量化模型。 |
| [ms1mv3_arcface_r18_rk3588_unquantized.rknn](<ms1mv3_arcface_r18_rk3588_unquantized.rknn>) | ArcFace 的 RK3588 非量化模型。 |
| [scrfd_500m_bnkps_shape640x640_rk3588_quantized.rknn](<scrfd_500m_bnkps_shape640x640_rk3588_quantized.rknn>) | SCRFD 人脸检测的 RK3588 量化模型。 |
| [scrfd_500m_bnkps_shape640x640_rk3588_unquantized.rknn](<scrfd_500m_bnkps_shape640x640_rk3588_unquantized.rknn>) | SCRFD 人脸检测的 RK3588 非量化模型。 |

默认加载哪些模型以 `../face_reid.py` 的配置为准。
