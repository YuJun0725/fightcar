# l_face_reidentification

基于检测模型和人脸特征模型进行身份比对的示例。

| 文件或目录 | 功能 |
|---|---|
| [main.py](<main.py>) | 打开摄像头，调用人脸检测与身份比对流程。 |
| [face_reid.py](<face_reid.py>) | 加载 FastDeploy 模型、建立人脸特征库并对检测到的人脸进行比对。 |
| [images/](<images/README.md>) | 建立人脸特征库时读取的参考图片。 |
| [models/](<models/README.md>) | 人脸检测和特征提取模型。 |
| [bale.png](<bale.png>) | 随示例提供的人脸图片。 |
| [bale2.png](<bale2.png>) | 随示例提供的人脸图片。 |
| [bale3.png](<bale3.png>) | 随示例提供的人脸图片。 |
| [result.png](<result.png>) | 随示例提供的结果图片。 |
