# h_color_shape_line

基于颜色分割的形状识别、直线检测和底盘联动示例。

| 文件或目录 | 功能 |
|---|---|
| [get_red_mask.py](<get_red_mask.py>) | 在 HSV 空间提取红色区域。 |
| [erosion_dilation.py](<erosion_dilation.py>) | 对颜色掩膜进行腐蚀、膨胀处理。 |
| [find_contours.py](<find_contours.py>) | 查找颜色区域轮廓。 |
| [hough.py](<hough.py>) | 使用霍夫变换检测直线。 |
| [uptech_color.py](<uptech_color.py>) | 颜色识别与底盘控制示例。 |
| [uptech_color_shape.py](<uptech_color_shape.py>) | 颜色、形状识别与底盘控制示例。 |
| [uptech_line_follow.py](<uptech_line_follow.py>) | 视觉巡线与底盘控制示例。 |
| [color_shape.jpeg](<color_shape.jpeg>) | 颜色及形状处理示例素材。 |
