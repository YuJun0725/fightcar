# k_yolo

在配套 Rockchip 环境中使用 RKNN 模型进行摄像头目标检测。

| 文件或目录 | 功能 |
|---|---|
| [uptech_yolo.py](<uptech_yolo.py>) | 加载通用 YOLO 模型并显示摄像头检测结果。 |
| [uptech_yolo_tank.py](<uptech_yolo_tank.py>) | 加载 shooting 模型并显示车辆类别检测结果。 |
| [rknnModel/](<rknnModel/README.md>) | 检测模型文件。 |
| [rknn_func/](<rknn_func/README.md>) | 通用类别的推理结果处理和线程池。 |
| [rknn_func_tank/](<rknn_func_tank/README.md>) | 车辆类别的推理结果处理和线程池。 |
