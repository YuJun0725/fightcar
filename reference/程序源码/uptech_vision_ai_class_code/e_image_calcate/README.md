# e_image_calcate

常见图像运算和变换示例，目录名称沿用老师原始命名。

| 文件或目录 | 功能 |
|---|---|
| [rgb_to_gray.py](<rgb_to_gray.py>) | 将彩色图像转为灰度图。 |
| [image_binary.py](<image_binary.py>) | 图像二值化。 |
| [image_filter.py](<image_filter.py>) | 均值、高斯等图像滤波。 |
| [image_laplacian.py](<image_laplacian.py>) | 使用 Laplacian 进行图像锐化。 |
| [image_trans.py](<image_trans.py>) | 图像平移等几何变换。 |
| [cat.jpeg](<cat.jpeg>) | 图像运算示例素材。 |
| [dog.jpeg](<dog.jpeg>) | 图像运算示例素材。 |
