# a_cds_python_control

底盘基础运动示例，各脚本包含底盘控制类及对应动作演示。

| 文件或目录 | 功能 |
|---|---|
| [uptech_move_forward.py](<uptech_move_forward.py>) | 前进动作示例。 |
| [uptech_move_backward.py](<uptech_move_backward.py>) | 后退动作示例。 |
| [uptech_turn_left.py](<uptech_turn_left.py>) | 向左转动示例。 |
| [uptech_turn_right.py](<uptech_turn_right.py>) | 向右转动示例。 |

这些示例配置了 ID 1～4，与当前小车的两驱动器配置不同。
