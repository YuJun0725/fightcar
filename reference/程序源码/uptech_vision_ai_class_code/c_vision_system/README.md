# c_vision_system

OpenCV 摄像头操作和图像读写、绘制入门示例。

| 文件或目录 | 功能 |
|---|---|
| [open_camera.py](<open_camera.py>) | 打开摄像头并显示视频帧。 |
| [camera_save.py](<camera_save.py>) | 摄像头图像保存示例。 |
| [camera_flip_resize.py](<camera_flip_resize.py>) | 对摄像头画面进行翻转和尺寸调整。 |
| [camera_draw.py](<camera_draw.py>) | 在摄像头画面上绘制图形。 |
| [camera_put_text.py](<camera_put_text.py>) | 在摄像头画面上叠加文字。 |
| [image_generate.py](<image_generate.py>) | 生成并显示空白图像。 |
| [draw_circle.py](<draw_circle.py>) | 生成图像并绘制圆形。 |
| [save_and_load.py](<save_and_load.py>) | 保存图像到文件后重新读取显示。 |
| [image_with_circle.jpg](<image_with_circle.jpg>) | 圆形绘制与图像读写示例使用的图片。 |
