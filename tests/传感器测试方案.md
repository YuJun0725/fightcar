# 传感器测试方案

按光电开关、距离传感器、灰度传感器分别测试。以下为待执行方案，记录表留空填写。

## 一、公共准备

- 传感器固定，目标板安装在轨道或角度夹具上；用尺子核对距离，明确测距起点。
- 角度为光轴与目标表面法线的夹角，正对记为 0°；倾斜时尽量绕光轴落点转动，保持该点距离不变。
- 每次只改变一个因素。目标尺寸应覆盖照射区域；颜色和粗糙度分别比较，目标材质、光泽写入记录。
- 每组条件至少重复 3 次；动态测试可每档速度重复 10 次。各传感器分别编号。
- 记录实际采集时间及轨道位置，核对位置与时间的对应关系。只有步数推算的位置应注明“估计”。
- 采样频率根据控制器实际能力确定；程序高频读取不一定获得同样频率的新数据。保留全部原始数据。

## 二、光电开关

读取 IO 状态；教程中检测到为 0、未检测到为 1，实测前先确认。

### 实验步骤

| 编号 | 实验 | 操作步骤 |
|---|---|---|
| P1 | 静态接近、释放 | 固定目标正对、光照和旋钮；从远处小步接近，在边界附近停稳观察并记录稳定触发距离；再远离，记录稳定释放距离；重复测量。 |
| P2 | 不同表面 | 分别更换黑、白、本色目标，重复 P1；固定颜色后再比较不同粗糙度，其余条件不变。 |
| P3 | 不同角度 | 使用同一目标，依次设置 0°、15°、30°、45°等角度，分别重复 P1，旋钮保持不变。 |
| P4 | 动态接近 | 固定目标正对，选择几档速度匀速靠近；同步采集时间、位置、IO，记录动态触发距离；与同条件 P1 结果比较。每次从未触发区域重新开始。 |

回差 = ｜释放距离 − 触发距离｜。P4 中目标越过检测边界时应处于匀速段；进入已验证的可靠检测区域仍无触发，记为漏检。

## 三、距离传感器

读取 ADC 原始值。测距范围按实物型号确认，ADC 值不直接等于距离。

### 实验步骤

| 编号 | 实验 | 操作步骤 |
|---|---|---|
| D1 | 静态多点 | 白色目标正对，固定光照；在有效范围内选多个距离点，停稳后连续采样，记录 ADC 均值和标准差，绘制曲线并尝试拟合。 |
| D2 | 动态靠近 | 相同目标正对，选择几档速度匀速靠近；同步记录时间、位置、ADC，绘制曲线，比较不同速度。 |
| D3 | 不同表面 | 更换黑、白、本色目标，分别重复 D1、D2；尺寸、角度、光照及速度档位一致。 |
| D4 | 不同夹角 | 同一目标设置若干角度，分别重复 D1、D2；实际距离统一沿光轴量到目标表面交点。 |
| D5 | 标定与验证 | 每个传感器用 D1 基准数据建立 ADC→距离的查表、插值或拟合关系；另选未参与标定的距离点验证，再将关系应用于动态记录。 |

标定不要求线性。先用同一条基准标定关系比较 D2～D4，观察材质、角度和速度引起的误差；如另建专用标定关系，应单独标注适用条件。

| 传感器编号 / 条件编号 | 次数 | 实际距离（cm） | ADC 均值 | 估计距离（cm） | 误差（cm） |

误差 = 估计距离 − 实际距离。汇总平均绝对误差、最大绝对误差；仅在标定覆盖且读数能区分距离的工作范围内使用换算关系。

**绘图与分析：**静态画“实际距离—ADC”，不同表面或角度分别画曲线；动态先画“时间—ADC”，标定后叠加“时间—实际距离 / 估计距离”，检查误差、滞后和突跳。

## 四、灰度传感器

读取 ADC，目标板与探头保持垂直。各组实验通过条件编号记录固定参数。

### 实验步骤

| 编号 | 实验 | 操作步骤 |
|---|---|---|
| G1 | 不同距离 | 固定光照和同一灰度样本，选择几个探头到表面的距离；每点停稳采样并重复。需要比较黑白区分能力时，再用另一块样本重复整组。 |
| G2 | 不同灰度 | 固定距离、角度和光照，依次测黑、深灰、中灰、浅灰、白样本；尽量使用相同基材和光泽，记录均值与波动。 |
| G3 | 不同光照 | 固定距离和同一样本，分别在正常照明、较暗、较强光照下测量；记录光源方向与位置。可对黑、白样本分别重复，检查原阈值是否仍适用。 |

**绘图与分析：**G1 画“距离—ADC”；G2 画按样本由黑到白排列的 ADC 均值及波动；G3 比较不同光照下的均值和波动。判断合适安装高度、灰阶区分能力及光照引起的偏移。未使用标准反射率样本时，不将读数直接解释为准确的灰度百分比。

动态实验逐条保存下表；静态实验也保留原始 ADC 序列，用于计算均值、标准差。固定的材料、角度和光照通过实验编号关联到条件表。

|---|---|---|---|---|---|---|
| | | | | | | |
| | | | | | | |
| | | | | | | |

- 原始记录可保存为 CSV，IO 与 ADC 按实验类型填写，未使用的列留空；灰度原始记录的距离换算为 cm，并保留记录表中的 mm 单位。
- 对距离和灰度数据，可在原始数据副本上比较滑动平均或中值滤波，注明窗口参数；同时评价静态波动与动态滞后，不能只看曲线是否平滑。
- 每项实验保留条件表、原始数据、统计表、曲线和简短结论。全部结果按实测填写。

采集接口参考 [uptech.py](src/board/uptech.py)：单通道示例为 `ADC_IO_GetInputLevel(channel)` 和 `ADC_Get_Channel(channel)`。实验软件每帧对所需类型分别调用一次 `ADC_IO_GetAllInputLevel()`、`ADC_Get_All_Channel()`，立即复制后选取通道；这不表示各通道在完全相同的瞬间采样。通道按实际接线确认。

## 六、软件操作对应

使用[传感器实验上位机](src/desktop/README.md)选择 P1～P4、D1～D5、G1～G3，填写上述条件，勾选通道并指定一个主通道。静态停稳后填距离并进行点采样，动态使用连续采集及运动开始/结束标记；实际轨道仍由人工操作。

统计表、条件快照和原始 CSV 自动保存在所选实验目录，PNG 曲线可手动导出。静态尺量距离与动态匀速估计位置分别记录来源，缺少位置时不生成检测距离或距离误差。原始数据不被滤波结果覆盖，断线的试次标明不完整。
