# IR ADC—距离：滤波结果

本目录是四组原始图的后续滤波版本。上一级四个原始 CSV、电机日志及 `raw_adc_distance/` 内的原图和对应数据均保持不变。

## 方法

- 四种速度统一采用**离线居中 5 点中值滤波**。在采样时间顺序上，对当前点及其前后各 2 点取中值。
- 边界重复端点值，不补零；每个速度分别处理，只使用之前已匹配的运动区间，不把启停前后静止阶段混进窗口。
- 中值窗口用于压制孤立尖峰；没有额外叠加均值或曲线拟合，也不强制曲线单调。
- 时间、估算距离和样本数量都不变；不删除行、不重采样，不调整或平移四组曲线。
- 灰色线为原始 ADC，彩色线为滤波 ADC。只画原图中的运动区间，启停前后完整数据仍可在原来的时间轴图查看。
- 这是利用未来相邻点的离线滤波，不能直接当成实时因果滤波的响应表现。滤波可以改变局部形状，不证明尖峰一定都是测量错误。

本次比较了 3 点中值、5 点中值和 5 点均值，选择 5 点中值作为第一版，避免均值被孤立尖峰拉高；没有以曲线相互重合为目标选择滤波方法。

## 窗口与不同速度

各 CSV 读取间隔约 0.05 s。完整 5 点窗口首尾跨度约 0.21 s，四组窗口在距离轴上的跨度不同：

| 电机设定（圈/分） | 运动样本数 | 窗口时间跨度中位数（s） | 窗口估算距离跨度中位数（cm） |
|---|---:|---:|---:|
| 25 | 432 | 0.207 | 0.645 |
| 50 | 218 | 0.206 | 1.284 |
| 100 | 111 | 0.207 | 2.516 |
| 200 | 56 | 0.206 | 4.981 |

此处跨度统计仅针对滤波窗口的时间/距离支持范围。相同点数窗口在高速下覆盖更长距离，可能影响局部细节比较；没有人为改用不同强度去消除速度间差异。

## 文件

- `filtered_adc_distance_4speeds.png` / `.svg`：四速度滤波前后对照总览。
- `filtered_adc_distance_25rpm.png`、`filtered_adc_distance_50rpm.png`、`filtered_adc_distance_100rpm.png`、`filtered_adc_distance_200rpm.png`：四张独立对照图。
- `filtered_adc_distance_overlay.png`：四条滤波结果叠加图。
- `filtered_motion_samples.csv`：817 个运动样本；保留对应表的全部原字段，新增 `adc_median5`，原始 `adc_value` 不覆盖。
- `filter_settings.json`：滤波参数、各组样本数和变化量、窗口跨度及输入 SHA-256。
- `plot_filtered.py`：重运行脚本。

图中的距离仍沿用原图的 `80 - 70*(t-start)/(end-start)` 匀速时间换算。标称线速度按用户提供的“200 圈/分约 25 cm/s”比例标注，并非位置实测；这次滤波不解决时钟、采集传输、传感器响应或机械启停造成的时间/距离误差。

从项目根目录运行：

```powershell
py -3 tests/log/1026senser_test/filtered_adc_distance/plot_filtered.py
```

只在本目录生成结果，不连接或启动实车。原始文件有变化时，脚本会拒绝沿用旧时间对应结果。
