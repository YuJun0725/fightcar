# 四种滑台速度的 IR 原始 ADC—距离图

数据来源：上一级的 `motor_log.txt` 和四个 `ir_sensor_25/50/100/200.csv`。所有原文件保持不变；没有读取或修改同目录的 Excel 文件。

## 图文件

- `raw_adc_distance_4speeds.png`：四种速度分别绘制的总览，坐标范围一致；另存同名 SVG。
- `raw_adc_distance_25rpm.png`、`50rpm.png`、`100rpm.png`、`200rpm.png`：每种速度的单独图片（文件名均以 `raw_adc_distance_` 开头）。
- `raw_adc_distance_overlay.png`：仅将运动区间的四组原始采样叠加比较。
- `raw_adc_time_alignment.png`：全部原始采样的时间轴，竖线和阴影标出日志确认的运动区间。

彩色线上的每个点都是对应原 CSV 的一行运动期间采样；连线只连接相邻采样点，没有插入 ADC 样本。距离图中的灰点是启停前后的原始采样，按假定的静止端点显示，不与运动曲线连线。它们的完整时序见时间轴图。

## 时间对应和距离换算

1. 电机日志明示 UTC+08:00。传感器 CSV 的时间戳未带时区，本次按同一 UTC+08:00 解释，不额外平移时间。不使用各文件自行归零的 `elapsed_time_s` 来匹配电机。
2. 每个 CSV 仅匹配落入其记录时间内、且速度相同的成功运行区间。开始点采用“指令已确认”的运行消息时间；结束点采用停止命令的 RX 应答时间。仅点击按钮但核对失败的启动不算运动开始。
3. 用户已确认每次均从 80 cm 靠近至 10 cm。因此在该区间使用匀速关系：

   ```text
   d(t) = 80 - 70 × (t - t_start) / (t_end - t_start)   [cm]
   ```

4. 这是根据起止距离及指令时间推算的距离，不是滑台位置传感器的实测读数。启停应答不等于精确机械启停时间，匀速和时钟对齐假设未通过独立位置记录验证。
5. 用户表示 200 圈/分“应该”约对应 25 cm/s。图标题按比例标注约 3.125、6.25、12.5、25 cm/s；这组标称值不是本次独立测速结果，也没有用它们重新伸缩 ADC 数据。

## 原始值与对应明细

- 共 1791 条原始采样，均为 ADC 通道 8；所有行和四个原字段原样保留在 `aligned_raw_samples.csv`，另增加原 CSV 行号、UTC+08 时间、相对运动时间、阶段和估算距离列。
- 阶段为 `before_motion`、`motion`、`after_motion`。不做滤波、均值、中值、平滑、去尖峰、异常值剔除、重采样或传感器响应补偿。运动区间的选择只按日志时间，不根据 ADC 大小选点。
- `alignment.json` 记录输入 SHA-256、匹配的日志行号、完整时间和各阶段样本数，可追溯对应关系。
- 图中确实存在启动前的低值/尖峰、以及停止应答后的持续 ADC 变化，均未删除，也没有通过平移时间强行消除。仅凭这些数据不判断是传感器响应、采集传输时差、时钟偏移还是机械停止过程造成的。
- 因此四条 ADC—距离曲线的差异目前应作为原始对照现象，不直接解释为已经测得的速度误差或传感器动态误差。
